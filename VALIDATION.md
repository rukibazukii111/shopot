## Что проверяют автотесты

- Журнал загрузок: все модели, оформление и компонент NVIDIA сохраняют идентификатор при успехе, ошибке и отмене.
- Ускорение NVIDIA: модульные тесты с локальным HTTP-сервером проверяют загрузку и распаковку только закреплённых DLL, докачку с места по Range, сервер без поддержки Range, испорченный и слишком большой временный файл, сбой при распаковке, нехватку места на диске и обрыв сети; компонент без метки или без любой DLL нужного размера не считается установленным; архивы, оставшиеся после готовой установки, удаляются при запуске движка, а недокачанный файл остаётся; сбой драйвера NVIDIA при опросе видеокарты не мешает запуску движка; видеокарта, которая через драйвер показывает чуть меньше 4096 МиБ (3584–4095 МиБ), считается картой на 4 ГБ, а 3583 МиБ уже мало. UI-тесты: карточки нет без NVIDIA, загрузка с прогрессом и шагом проверки, переключатель «Использовать видеокарту» сохраняется, после установки карточка показывает место на диске (1,8 ГБ), при видеопамяти 2 ГБ карточка без кнопки загрузки с пояснением, и в пояснении стоит минимум, который сообщает движок.

- **Node:** настройки и сохранность истории; словарь, сниппеты и профили (дубли, длины, старый `store.json`); вставка Unicode, переносы строк как CRLF на Windows и отказ при смене окна, зажатых модификаторах, нет разрешения, изменился буфер, отмена; предложения словаря из правок; экспорт SRT и Markdown; сборка диалога созвона и отбрасывание эха; журнал: только разрешённые поля, все модели, языки, режимы и оформление из настроек, сообщение только у ожидаемых ошибок движка, папка пользователя как `~`, три файла по 5 МБ, файл, занятый другой программой, не стирает старые части, удаление строк старше срока не оставляет копий, сбой записи не мешает работе, все части читаются одним текстом по порядку; ссылка «Сообщить о проблеме»: только анкета и версии, страница GitHub по https для репозитория из package.json, длина ссылки; связь с движком сохраняет тип ошибки и не передаёт в журнал вывод упавшего движка.

## Ручные проверки

- **Распознавание** (18.09.2026): импорт WAV, запись WEBM/Opus через Chromium, история, удаление временного аудио; Python-прогон без сети. В 0.2.3 large-v3 проверена с папкой аудио, перенаправленной в MSIX LocalCache.
- **Оформление** (18.09.2026): правила на 13 длинных диктовках — абзацы расставляются, списки только при подряд идущих порядковых словах. На записи 81 с абзацы совпали с паузами. Заполнитель «э-э» убран, остальной текст совпал.
- **Умное оформление** (24.09.2026, RTX 5060, llama.cpp b11040 Vulkan, Qwen3-4B Q4_K_M): скачивание со сверкой SHA-256, 13 диктовок за 0,17–1,4 с. GigaAM и Whisper large-v3 вместе с оформлением работают без падения OpenMP.
- **Голосовые команды и сниппеты** (26.09.2026, голос Windows «Microsoft Irina», GigaAM): «новый абзац» и «с новой строки» сработали; сниппет сработал внутри предложения после поддержки падежей. Даты, суммы и проценты GigaAM уже пишет цифрами. Синтезированный голос чище живой речи.
- **Перевод** (26.09.2026): large-v3 перевела синтезированную фразу за 7,8 с. Голосовые команды при переводе становятся словами, поэтому в этом режиме они не работают.
- **Субтитры:** на записи 597 с с GigaAM — 132 реплики, все 1022 слова на месте, без наложений, распознавание не замедлилось.
- **Профили:** на Windows имя приложения определяется верно (node.exe, firefox.exe, несуществующий процесс — неизвестно).
- **Созвоны:** занятый микрофон Discord найден в реестре за 5 мс. Стерео-кусок, собранный как в приложении, GigaAM распознал по каналам без смешивания.
- **Интерфейс** (18.09.2026): все экраны и четыре состояния виджета на снимках с поддельным распознаванием, 1240×820 и 1000×690, без ошибок в консоли.

Ускорение NVIDIA, загрузка компонента (8 октября 2026, Windows, RTX 5060 8 ГБ, драйвер 610.88). Видеокарта определена через драйвер (NVML): «NVIDIA GeForce RTX 5060», 8151 МиБ. Через протокол движка скачаны настоящие архивы с PyPI (cuBLAS 12.8.4.1 и cuDNN 9.10.2.21, 1,26 ГБ). Процесс движка убит после 302 МБ; повторная команда продолжила загрузку с 303 МБ, сверила SHA-256 обоих архивов, распаковала 10 DLL (1,7 ГБ) и записала метку: 51 с от повторного запуска. Отдельный проверочный скрипт (не код приложения) запустил Whisper large-v3 turbo на видеокарте с этими DLL, float16: загрузка модели 2,6 с, запись 81 с — 2,1 с с первого раза и 1,6 с со второго. ctranslate2 ищет `cublas64_12.dll` по имени и не видит папку из `os.add_dll_directory`, поэтому cuBLAS нужно загрузить заранее по полному пути; cuDNN подхватывается сам. Видеокарты NVIDIA с памятью меньше 4 ГБ, старые драйверы и ноутбуки с двумя видеокартами не проверялись: только тестами с подставленной видеокартой.

## Замеры

Windows, Ryzen 5 7500F, CPU / INT8. Отдельные запуски, не универсальная оценка скорости.

| Модель | Запись 81 с | Фраза 3 с | Память |

| GigaAM v3 | 3,9 с | 0,17 с | пик 0,36–0,52 ГБ |
| Whisper large-v3 turbo, 4 потока | 16,0 с | ~4,5 с | 0,9 ГБ, при загрузке до 1,9 ГБ |

- Упакованный движок: GigaAM на той же записи — 3,8 с вместе с загрузкой модели.

## Как повторить

- Распознавание своей записи: `scripts/evaluate.py sample.wav --data-dir .local --output .private/comparison.json`.
- Упакованное приложение с микрофоном: `scripts/verify-microphone.cjs`. `SHOPOT_EXECUTABLE` — путь к приложению, `SHOPOT_MODEL` — модель, `SHOPOT_MODELS_DIR` — скачанные модели, `SHOPOT_REDIRECT_AUDIO=1` — перенаправление папки аудио. Данные теста лежат в `.private`.
- Тест с настоящей моделью оформления: `SHOPOT_LLM_TEST=<runtime>;<model.gguf>`.

## Граница вставки

Вставка подтверждает отправку стандартного сочетания, но не читает чужое поле после неё. На Windows сравниваются исходное окно и идентификатор фокуса; поля внутри одной веб-страницы могут иметь общий идентификатор. На macOS дополнительно сравнивается элемент Accessibility, если он доступен. При неопределённом результате текст остаётся в истории.
