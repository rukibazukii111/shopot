Локальная диктовка для Windows и macOS.

Исправления 0.2.3:

- Исправлена ошибка «Аудиофайл должен находиться в папке данных приложения» при перенаправлении папки Windows.
- Виджет скрывается сразу после остановки записи. Долгое распознавание идёт в фоне.
- При ошибке аудио сохраняется для повторной обработки; незавершённые записи доступны после перезапуска приложения.
- Короткие уведомления об ошибке закрываются через 3 секунды. Технический префикс IPC убран из сообщения в интерфейсе.

- Ctrl+Shift+Space на Windows, ⌘+Shift+Space на Mac: начать / закончить диктовку из любого приложения.
- Компактный виджет с уровнем голоса, временем, остановкой и отменой. Главное окно остаётся скрытым.
- Готовый текст вставляется в исходное приложение через буфер обмена. Enter не нажимается. При смене окна текст остаётся в буфере и истории.
- Whisper small, large-v3 turbo и large-v3; русский, английский и автоопределение языка; личный словарь и три режима пунктуации.
- Исправлены отмена при ожидании микрофона, очистка отменённых записей, потеря черновика контекста, работа с асинхронным буфером обмена и гонки при отмене распознавания.
- Кнопка показывает текущее состояние обработки; переход в другой раздел возвращает страницу к началу.

Скачай `win-x64.exe` для Windows, `mac-arm64.dmg` для Mac с Apple Silicon или `mac-x64.dmg` для Intel Mac. Python отдельно не нужен. Модель скачивается при первом запуске, затем распознавание работает без интернета.

На Mac перемести приложение в Applications. Для микрофона и автовставки нужны разрешения системы; кнопка проверки автовставки находится в настройках Шёпота. Сборки пока без сертификата разработчика и нотариализации Apple: при первом запуске система может потребовать «Всё равно открыть» в настройках безопасности.

Распознавание использует CPU / INT8. Автовставка зависит от поддержки обычной команды вставки принимающим приложением; окна Windows с повышенными правами могут её блокировать. Если вставка недоступна, текст можно взять из истории. Реальный ввод на Mac требует проверки на пользовательском устройстве.
