Локальная диктовка для Windows и macOS. Что нового в 0.3.0:

- Новая модель по умолчанию — «Быстрая» (GigaAM v3, русский): короткая фраза распознаётся за доли секунды вместо нескольких секунд у Whisper.
- Абзацы и списки по паузам и словам вроде «во-первых». На Windows с видеокартой можно скачать «Умное оформление» на локальной нейросети. Слова при этом не меняются.
- Убираются звуки-заполнители: «ааа», «э-э», «мм».
- Голосовые команды «новый абзац» и «новая строка».
- Сниппеты: короткая фраза вставляет сохранённый текст, например почту или реквизиты.
- Профили приложений: свой режим и оформление для конкретной программы.
- Исправления в истории предлагают новые слова для словаря.
- Удержание сочетания клавиш: держи, пока говоришь, и отпусти.
- Перевод русской речи на английский (модели «Лёгкая» и «Полная»).
- Сохранение расшифровки в TXT, Markdown и субтитры SRT.
- Запись созвонов на Windows: Шёпот предлагает записать звонок и показывает его диалогом «Я» / «Собеседники».
- Новый тёмный интерфейс. Модель выгружается из памяти после простоя и сразу загружается снова по сочетанию клавиш. На компьютере с 8 ГБ тяжёлые модели предупреждают перед выбором.

Скачай `win-x64.exe` для Windows, `mac-arm64.dmg` для Mac с Apple Silicon или `mac-x64.dmg` для Mac с Intel. Сборки без подписи разработчика: как их открыть, написано в README. На Mac вставка текста и удержание клавиш ещё не проверены на настоящем устройстве.
