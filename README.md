# Шёпот / Shopot

Локальная диктовка для Windows и macOS: горячая клавиша, небольшой виджет и вставка текста туда, где стоял курсор. Распознавание на GigaAM и Whisper, без аккаунта и подписки.

**[Скачать приложение](https://github.com/rukibazukii111/shopot/releases)**

| Компьютер | Файл в Releases |
|---|---|
| Windows 10/11, x64 | `Shopot-…-win-x64.exe` |
| Mac с Apple Silicon, macOS 14+ | `Shopot-…-mac-arm64.dmg` |
| Mac с Intel, macOS 13+ | `Shopot-…-mac-x64.dmg` |

Это ранняя версия. Сборки пока без сертификата разработчика и нотариализации Apple. На Mac скопируй Shopot в Applications; если система блокирует запуск, используй штатное «Всё равно открыть» в Системных настройках → Конфиденциальность и безопасность. Контрольные суммы установщиков публикуются в `SHA256SUMS.txt`.

## Как пользоваться

1. Установи Шёпот и скачай модель в разделе «Модели». Python уже включён в установщик.
2. Поставь курсор в поле сообщения, заметку или документ.
3. Нажми **Ctrl+Shift+Space** на Windows или **⌘+Shift+Space** на Mac. Появится виджет записи.
4. Продиктуй текст и нажми сочетание ещё раз. Виджет сразу скроется, распознавание продолжится в фоне. Готовый текст вставится в исходное приложение. **Esc** во время записи отменяет её. После остановки Esc снова работает в других приложениях; отменить распознавание можно в главном окне Шёпота.

Шёпот не нажимает Enter. Текст остаётся в буфере и истории. Если во время обработки переключиться в другое окно, автоматической вставки не будет: вернись в нужное поле и вставь вручную. При записи кнопкой в самом Шёпоте и импорте файла результат появляется в истории; копирование регулируется отдельной настройкой. Закрытие главного окна оставляет приложение в трее; выход — через меню значка.

На Mac разреши микрофон. Для автовставки также нужен «Универсальный доступ» в настройках конфиденциальности macOS; кнопка «Разрешить / проверить» есть в настройках Шёпота. Сочетание может быть занято другим приложением: Шёпот сообщает об этом. Приложения с нестандартной командой вставки и окна Windows от администратора могут требовать ручной вставки.

## Распознавание

- GigaAM v3 (~216 МБ, только русский) — модель по умолчанию: короткая фраза распознаётся за доли секунды, пунктуация и заглавные буквы есть.
- Whisper small (~484 МБ), large-v3 turbo (~1,6 ГБ), large-v3 (~3,1 ГБ) — для английского, автоопределения языка и сравнения качества. Whisper обрабатывает звук окнами по 30 секунд, поэтому даже короткая фраза занимает несколько секунд.
- Модель начинает загружаться при нажатии сочетания, пока идёт запись, и выгружается из памяти после 10 минут простоя. Работа на CPU / INT8, не больше 4 потоков; ускорение GPU пока не подключено.
- Личный словарь имён, сленга и терминов. До 100 слов; для Whisper первые 500 символов используются как подсказка модели, для GigaAM словарь работает только через замены. Можно добавить точные варианты ошибок для замены целых слов и фраз.
- Оформление текста в режиме «Естественно»: абзацы по длинным паузам и словам вроде «теперь», «дальше», «в общем»; нумерованный список для «во-первых, во-вторых», «первое, второе», «…это раз. Второе…»; маркированный — для «нужны: молоко, хлеб и яйца». Слова не меняются, добавляются только переносы строк и маркеры списков. Отключается в настройках.
- «Умное оформление» (Windows x64, отдельная загрузка ~2,4 ГБ в разделе «Модели»): абзацы и списки расставляет локальная нейросеть Qwen3-4B через llama.cpp на видеокарте (Vulkan: NVIDIA, AMD, Intel), около секунды на диктовку. Модель только выбирает метку для каждого предложения, текст собирается из исходных предложений, поэтому слова не меняются. Без сервера и без отправки текста в сеть. При любой ошибке используются обычные правила.
- «Естественно» сохраняет пунктуацию модели и применяет словарь. «Минимум пунктуации» убирает конечные знаки у слов, сохраняя версии и адреса. «Исходный результат» не применяет наши замены.
- История с редактированием, поиском, экспортом TXT, исходным текстом и оценками уверенности модели. Хранение аудио включается отдельно.

Исправление текста в истории не переобучает модель. Подсказки помогают, но качество сленга и пунктуации зависит от записи и модели. Оценка уверенности не является вероятностью правильного слова. Для сравнения точности нужна проверенная человеком расшифровка.

## Данные

Аудио и тексты обрабатываются на компьютере и не отправляются внешним сервисам. Интернет нужен для явной загрузки модели с Hugging Face. Версии моделей закреплены конкретными ревизиями. Временное аудио удаляется после успешной обработки или отмены новой записи, если хранение отключено. При ошибке или прерывании обработки аудио сохраняется: в главном окне можно повторить распознавание с текущей моделью или удалить запись. Отмена повторной обработки сохраняет аудио для следующей попытки. Повторный результат появляется в истории, без автовставки. История хранится локально открытым JSON; это не зашифрованное хранилище.

- Windows: `%APPDATA%/Shopot`
- macOS: `~/Library/Application Support/Shopot`
- Запуск из исходников: `.local` в проекте

Обновление сохраняет настройки, словарь, историю и скачанные модели. Пользовательские данные и модели не включены в GitHub и установщики.

## Разработка

Нужны Node.js 24 и Python 3.11 (также поддерживается 3.12):

```sh
npm ci
npm run setup
npm start
```

`npm start` запускает отдельное Electron-приложение. Backend общается с ним через JSON lines по stdin/stdout, локального HTTP-сервера нет. В renderer отключены Node.js, произвольная навигация и внешняя сеть; у виджета отдельный узкий IPC. Автовставка использует Win32 SendInput либо macOS Accessibility/CoreGraphics через Koffi.

```sh
npm test
npm run test:ui
# Windows:
.venv/Scripts/python.exe -m pip install -r backend/requirements-dev.txt
.venv/Scripts/python.exe -m pytest -q
# macOS: вместо Scripts/python.exe используй bin/python
npm run dist -- --publish never
npm run test:packaged
```

Сборку нужно делать на целевой ОС и архитектуре. Workflow `Desktop builds` собирает Windows x64, Mac ARM64 и Mac Intel, проверяет упакованный движок и публикует установщики для тегов `v*`. Облачная сборка не требует приватных записей или моделей.

UI-тесты используют тестовый микрофон и изолированное поле ввода.

Проверка Win32-вставки включается отдельно: `SHOPOT_NATIVE_INPUT_TEST=1 npm run test:ui` (в PowerShell сначала `$env:SHOPOT_NATIVE_INPUT_TEST = '1'`). Она требует интерактивного рабочего стола и активного тестового окна; тест проверяет его системный PID перед вводом. В обычном CI этот тест пропускается.

Для проверки настоящего распознавания на своей записи:

```sh
.venv/Scripts/python.exe scripts/evaluate.py sample.wav --data-dir .local --output .private/comparison.json
node scripts/verify-microphone.cjs sample.wav
```
