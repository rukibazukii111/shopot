# Шёпот / Shopot

Локальная диктовка для Windows и macOS. Нажми сочетание клавиш в любом приложении, скажи текст — он появится там, где стоял курсор. Речь распознаётся на твоём компьютере: без аккаунта, подписки и отправки звука в интернет.

**[Скачать](https://github.com/rukibazukii111/shopot/releases)**

| Компьютер | Файл |
|---|---|
| Windows 10/11, x64 | `Shopot-…-win-x64.exe` |
| Mac с Apple Silicon, macOS 14+ | `Shopot-…-mac-arm64.dmg` |
| Mac с Intel, macOS 13+ | `Shopot-…-mac-x64.dmg` |

Ранняя версия. Сборки без подписи разработчика:

- Windows: если появилось окно SmartScreen, нажми «Подробнее» → «Выполнить в любом случае».
- Mac: перенеси Шёпот в Applications. При блокировке нажми «Всё равно открыть» в Системных настройках → Конфиденциальность и безопасность.

Контрольные суммы — в `SHA256SUMS.txt` рядом с установщиками.

## Зачем

Печатать долго. Облачная диктовка отправляет голос на чужие серверы, просит подписку и хуже знает русский. Шёпот работает офлайн и сделан прежде всего для русской речи: пунктуация, абзацы, списки, свои термины.

Для кого:

- кто много пишет в мессенджерах, почте и документах;
- кто диктует длинные промпты для ИИ с английскими терминами;
- кто хочет расшифровку созвона без бота в звонке и без облака.

## Четыре правила

Каждая функция их соблюдает. Изменение, которое нарушает правило, — ошибка.

1. Аудио и текст не покидают компьютер. Интернет нужен только для загрузки модели по кнопке.
2. Шёпот не нажимает Enter и ничего не отправляет за тебя.
3. Шёпот не меняет твои слова. Он добавляет пунктуацию, абзацы и списки, применяет словарь и сниппеты, убирает «ааа» и «э-э». Свой текст модель пишет только при переводе.
4. Продиктованное не теряется. Аудио хранится до успешного распознавания, текст попадает в историю.

## Как пользоваться

1. Установи Шёпот и скачай модель на вкладке «Модели».
2. Поставь курсор в поле ввода.
3. Нажми **Ctrl+Shift+Space** (на Mac **⌘+Shift+Space**) и говори.
4. Нажми сочетание ещё раз. Или держи его, пока говоришь, и отпусти.

Текст вставится в то же поле. **Esc** во время записи отменяет её. Если до вставки ты переключился в другое окно, Шёпот не вставит текст: он останется в буфере обмена и в истории.

На Mac разреши «Микрофон» и «Универсальный доступ» (для вставки). Кнопка проверки есть в настройках Шёпота.

## Что умеет

**Диктовка**

- Сочетание клавиш в любом приложении: нажать-нажать или удерживать.
- Маленький виджет поверх окон: уровень голоса, время, стоп и отмена. Фокус он не забирает.
- Запись кнопкой в главном окне. Расшифровка аудио- и видеофайла до 100 МБ.

**Модели**

| В приложении | Модель | Размер | Когда выбирать |
|---|---|---|---|
| Быстрая | GigaAM v3 | 216 МБ | По умолчанию. Только русский, фраза за доли секунды |
| Лёгкая | Whisper small | 484 МБ | Английский или автоопределение языка на слабом компьютере |
| Точная | Whisper large-v3 turbo | 1,6 ГБ | Сленг и термины, английский |
| Полная | Whisper large-v3 | 3,1 ГБ | Лучшее качество Whisper, больше памяти и времени |

Whisper тратит несколько секунд даже на короткую фразу. «Лёгкая» и «Полная» умеют переводить русскую речь на английский.

**Текст**

- Режимы: «Естественно» (пунктуация модели), «Минимум знаков», «Исходный результат» (без обработки Шёпота).
- Оформление: абзацы и списки по правилам, «Умное» на локальной нейросети или одним абзацем.
- Убирает звуки-заполнители: «ааа», «э-э», «мм».
- Голосовые команды: «новый абзац», «новая строка».
- Личный словарь: правильное написание и частые ошибки модели. Исправления в истории предлагают новые слова.
- Сниппеты: короткая фраза превращается в готовый текст, например почту или реквизиты.
- Профили приложений: свой режим, оформление и «без точки в конце» для конкретной программы.

**История**

- Поиск, правка, исходный текст модели.
- Сохранение в TXT, Markdown или субтитры SRT.
- Неудачная запись остаётся в списке: её можно распознать снова.
- Аудио хранится, только если это включено в настройках.
- Срок хранения: всегда, 30 или 7 дней. Старые записи удаляются сами вместе с аудио, незавершённые остаются.

**Созвоны**

Шёпот замечает, что звонок занял микрофон (Discord, Zoom, Telegram, браузер), и предлагает записать. Пишет твой микрофон и звук собеседников, без бота в звонке. В истории появляется диалог «Я» / «Собеседники». «Скопировать для резюме» кладёт расшифровку с просьбой о резюме в буфер обмена для любого чат-ассистента.

## Где что работает

| | Windows x64 | Mac |
|---|---|---|
| Диктовка, вставка, модели, словарь, история | да | да, но вставка и удержание клавиш не проверены на настоящем Маке |
| Умное оформление (~2,4 ГБ, нужна видеокарта) | да | нет |
| Созвоны | да | нет |

Только автоматическая сборка, без настоящего устройства: Mac с Intel, Windows 10, видеокарты AMD и Intel.

## Ограничения

- Распознавание идёт только на процессоре. Видеокарта его не ускоряет.
- На компьютере с 8 ГБ памяти «Точная» и «Полная» работают медленно. Шёпот предупреждает перед выбором.
- Вставка не работает в окнах, запущенных от администратора, и в программах с нестандартной вставкой. Возьми текст из истории.
- Сочетание клавиш пока нельзя изменить. Если его заняла другая программа, Шёпот сообщит.
- Исправления в истории не переобучают модель.
- История хранится открытым JSON, без шифрования.

## Данные

Всё лежит в одной папке:

- Windows: `%APPDATA%/Shopot`
- macOS: `~/Library/Application Support/Shopot`
- запуск из исходников: `.local` в проекте

Там настройки, словарь, история, модели и аудио. Обновление их сохраняет. Закрытое окно оставляет Шёпот в трее, выход — через меню значка.

В подпапке `logs` — журнал для разбора ошибок: до трёх файлов по 5 МБ, старые строки удаляются сами. Каждая строка журнала начинается с даты и времени. В журнале версии, длительность этапов, пик памяти, причины отказа вставки, ошибки, название программы, куда шла вставка, а у созвонов — программа, время начала и длительность. Текста диктовок, аудио, буфера, словаря, сниппетов, заголовков окон и имён файлов в нём нет; папка пользователя в путях заменена на `~`. Журнал никуда не отправляется. В самом низу Настроек, у пункта «Журнал», три кнопки: «Открыть папку», «Сохранить в файл» (все части одним файлом) и «Сообщить о проблеме». Последняя открывает в браузере новую задачу на GitHub с короткой анкетой и версиями приложения и системы. Нужен аккаунт GitHub, задачу видят все. Журнал к ней прикладывают вручную, если хотят.
